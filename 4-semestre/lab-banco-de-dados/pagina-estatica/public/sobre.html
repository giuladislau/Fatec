Sobre o Projeto

Aprenda a servir arquivos estáticos com Node.js

O que você aprendeu:

  • Estruturar pastas para arquivos estáticos
  • Configurar Express para servir HTML, CSS e JS
  • Separar código frontend do backend
  • Criar navegação entre páginas
  • Fazer requisições à API com fetch()
  • Aplicar estilos modernos com CSS

Tecnologias:

Backend: Node.js + Express
Frontend: HTML5 + CSS3 + JavaScript (ES6+)
Arquitetura: Arquivos estáticos separados
